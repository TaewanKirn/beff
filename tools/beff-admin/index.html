전체 화면 플로우 (Figma · 1112 검증 › 8)

상자를 누르면 에뮬레이터의 베프가 그 화면으로 바뀝니다. 숫자가 붙은 상자는 상태를 골라 엽니다. 흐린 상자는 바로 열 수 없는 화면이라 직전 화면으로 보내고 무엇을 누르면 되는지 알려 줍니다. 색 칩(→ B-1 홈 등)을 누르면 그 상자로 갑니다. 지금 화면은 굵은 틸 테두리로 표시합니다.

플로우별 차량 상태

버튼 하나가 「여정 상태 → 기어(→ 문 열림)」를 차례로 보냅니다. 기어는 앱 안에서만 덮어씁니다(차량에는 아무것도 보내지 않음). Virtual Console 값보다 우선하니 끝나면 「실제 기어 따르기」로 풀어 주세요.
